# asm-lab — браузерный эмулятор ассемблера для лабораторных работ

SPA-эмулятор ассемблера: настоящий NASM и GNU ld собирают программу внутри
WebAssembly, x86-64 код исполняется встроенным эмулятором blink — всё
на стороне клиента, без сервера и без установки тулчейна.

## Возможности

- **Два режима.** `x86-64` — полный цикл: NASM → ld → загрузка ELF → пошаговое
  исполнение, реальные регистры и стек. `16 бит (учебный)` — `bits 16` / `int 21h`,
  проверка ограничений и сборка в плоский `.bin`; запуск недоступен, так как
  blink работает только в long mode (об этом предупреждает панель).
- **Ограничения лабораторных Л/Р 1–5** включаются прямо ссылкой:
  `?lab=3&z=4`, `lab=-1`… поддерживается `z=-1` («все задачи»).
- **Проверка до компиляции.** Отдельная функция `checkRestrictions()` разбирает
  исходник (мнемоники, операнды, регистры, обращения к памяти, директивы) и
  объясняет каждое нарушение до того, как код попадёт в NASM.
- **Отладчик.** Дизассемблер с подсветкой текущей инструкции, регистры в пяти
  представлениях (RAX/EAX/AX/AH/AL и т.п.), флаги, стек с ASCII-колонкой,
  память 16 байт в строке (hex + ASCII), терминал с выводом программы.
- **Темы.** Тёмная DOSBox-тема по умолчанию и светлая «документация» — переключение
  кнопкой в панели управления.
- **Ссылка с кодом.** Кнопка «Ссылка» упаковывает исходник (LZ-сжатый base64)
  и ограничения в `?code=…&lab=…&z=…`.

## Команды

```bash
npm install --legacy-peer-deps   # зависимости
npm run dev                      # dev-сервер на http://localhost:5173
npm run build                    # tsc --noEmit && vite build
npm run preview                  # предпросмотр собранного бандла
npm run typecheck                # только проверка типов
npm test                         # vitest
node tools/validate-examples.mjs # прогон всех примеров через настоящий wasm
node tools/smoke.mjs             # smoke-тест UI в jsdom (сборка, шаг, запуск)
```

## Ссылки-параметры

| Параметр  | Значение                         | Смысл                          |
| --------- | -------------------------------- | ------------------------------ |
| `lab`     | `1`…`5`                          | лабораторная работа            |
| `z`       | `-1`, `0`…`10`                   | задача; `-1` — все задачи      |
| `mode`    | `x64` \| `x16`                   | режим ассемблера               |
| `theme`   | `dark` \| `light`                | тема оформления                |
| `example` | `lab1-1`, `lab3-memory`, …       | готовый пример                 |
| `code`    | base64(LZ(исходник))             | исходник в ссылке              |

## Служебный эпилог

Проверка ограничений не должна ругаться на код завершения программы: он зависит
от ОС, а не от задания. Строка-маркер

```asm
; @service — служебный выход, не входит в проверку ограничений
    mov ax, 60
    syscall
```

выключает проверку для всех строк ниже (в том числе `syscall`, `int 21h`,
`xor edi, edi`). Всё, что выше маркера, проверяется как обычно.

## Структура

```
src/
  core/
    blink/         обёртка над wasm-движком (struct, blink, session)
    restrictions/  каталог Л/Р, парсер исходника, валидатор
    asm/modes.ts   режимы x64/x16
    registers.ts   семейства регистров и их псевдонимы
  ui/
    editor/        редактор с подсветкой и номерами строк
    widgets/       панели: регистры, дизассемблер, стек, память, ограничения, терминал
  app/             App, маршрут из query-параметров, шаринг ссылки, стили
  assets/          blinkenlib.js/.wasm, nasm.elf, gnu-ld.elf (из x86-64-playground)
  examples/        готовые примеры под каждую лабораторную
```
